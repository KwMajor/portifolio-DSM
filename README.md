## Portfólio — DSM (Fatec São José dos Campos)

Portfólio pessoal de **Matheus Ramos**, estudante de **Desenvolvimento de Software Multiplataforma (DSM)** na Fatec São José dos Campos. Reúne páginas estáticas com perfil, projetos acadêmicos, formação e o stack de tecnologias utilizado ao longo do curso.

**Online:** https://rmsmatheus.vercel.app/

### Tecnologias do portfólio
- HTML5
- CSS3 (Flexbox + CSS Grid)
- Bootstrap 5
- Hospedagem: Vercel

### Estrutura do repositório
- `index.html` — página inicial com apresentação e contato
- `projetos.html` — projetos integradores (cards padronizados em grade 2x2)
- `formacao.html` — formação acadêmica e certificações
- `tecnologias.html` — stack de linguagens, frameworks e ferramentas
- `css/style.css` — estilos do site
- `imagens/` — ícones e capas dos projetos
