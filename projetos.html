Projeto API 4° Semestre 2026-1 - Tecsus

Estação Meteorológica IoT
Desenvolvimento de uma plataforma IoT para coleta, transmissão e processamento de dados climáticos em tempo real por meio de redes de sensores sem fio. O sistema amplia o portfólio da Tecsus em monitoramento ambiental, viabilizando previsões ultra-localizadas para agricultura de precisão (produção de soja em larga escala).
Principais funcionalidades:
• Coleta de dados de vento (direção e velocidade), chuva, umidade do ar, temperatura e pressão atmosférica
• Modelo de dados dinâmico para configuração flexível de sensores e estações
• CRUD de estações, parâmetros, alertas e usuários com Controle de Acesso por Papéis (RBAC)
• Dashboards interativos com análise meteorológica
• Sistema automatizado de alertas para condições climáticas críticas
Objetivo:
Entregar uma estação meteorológica acessível e escalável que permita ao cliente final acompanhar variáveis climáticas em tempo real, gerar relatórios consolidados e apoiar a tomada de decisão no campo.

Tecnologias Utilizadas
Next.js React TypeScript Node.js Docker Jest pnpm Vercel GIT
Contribuições Pessoais

Atuação no desenvolvimento Back-end em Node.js/TypeScript, com foco em modelagem de dados dinâmica para sensores, endpoints REST para CRUD de estações, parâmetros e alertas, e implementação do controle de acesso por papéis (RBAC). Contribuí também com mentoria técnica ao time, padronização de código (ESLint/Prettier) e organização do fluxo Ágil para destravar entregas contínuas a cada sprint.

Hard Skills Efetivamente Desenvolvidas

Soft Skills Efetivamente Desenvolvidas

Projeto API 3° Semestre 2025-2 - GSW

Software para controle de equipes
Desenvolvimento de uma aplicação web focada na gestão colaborativa e ágil de equipes e projetos. A plataforma adota uma filosofia de "permissão aberta" (autogestão), eliminando hierarquias rígidas de acesso. O objetivo é maximizar a produtividade e reduzir gargalos burocráticos, permitindo que todos os membros tenham autonomia total.
A aplicação exibe informações estratégicas em tempo real, incluindo:
• Equipes, Projetos, Notificações e Tasks
• Login com autenticação JWT e Login com Google
• Sistema de comentários e anexos em tasks
Objetivo:
Desnvolver uma aplicação web para facilitar o gerenciamento de tarefas individuais e em equipe. Com interface intuitiva e responsiva, o sistema permite que usuários criem, atribuam e acompanhem tarefas de forma colaborativa, integrando comentários, anexos e notificações.

🏛️ Plataforma de Transparência Política

A plataforma reúne dados públicos para que o eleitorado acompanhe seus representantes além do voto, incluindo:
• Perfil e histórico de cada vereador
• Votações, proposições e presença em sessões

🎯 Objetivo:
Aproximar o eleitor da Câmara Municipal por meio de um ambiente digital que reúna informações relevantes e ajude a identificar quais políticos realmente defendem os interesses da população.
